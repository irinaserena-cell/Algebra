Подготовка к экзамену по алгебре

Основные понятия и формулы

Основные уравнения прямой
1. Общее уравнение прямой

Общее уравнение прямой имеет вид:

Ax + By + C = 0

Где $A$, $B$ и $C$ — постоянные, причем $A$ и $B$ не равны нулю одновременно.

2. Уравнение прямой с угловым коэффициентом

Уравнение прямой с угловым коэффициентом:

y = kx + b

Где $k$ — угловой коэффициент ($k = \tan \alpha$), $b$ — отрезок, отсекаемый прямой на оси $Oy$.

3. Уравнение прямой в отрезках

Уравнение прямой в отрезках:

\frac{x}{a} + \frac{y}{b} = 1

Где $a$ — отрезок, отсекаемый прямой на оси $Ox$, $b$ — отрезок, отсекаемый прямой на оси $Oy$.

4. Каноническое и параметрическое уравнения прямой

Каноническое уравнение прямой:

\frac{x - x_0}{m} = \frac{y - y_0}{n}

Где $(x_0, y_0)$ — точка, через которую проходит прямая, и $(m, n)$ — координаты направляющего вектора прямой.

Параметрическое уравнение прямой:

\begin{cases} x = x_0 + mt \\ y = y_0 + nt \end{cases}

Где $(x_0, y_0)$ — точка, через которую проходит прямая, $(m, n)$ — координаты направляющего вектора прямой, и $t$ — параметр.

5. Нормальный и направляющий вектор прямой

Нормальный вектор прямой:

Для общего уравнения прямой Ax + By + C = 0, нормальный вектор $\vec{n}$ имеет координаты:

\vec{n} = (A, B)

Направляющий вектор прямой:

Для канонического/параметрического уравнения прямой \frac{x - x_0}{m} = \frac{y - y_0}{n}, направляющий вектор $\vec{d}$ имеет координаты:

\vec{d} = (m, n)

Для общего уравнения прямой Ax + By + C = 0, направляющий вектор может быть:

\vec{d} = (-B, A) \quad \text{или} \quad \vec{d} = (B, -A)
6. Угол между прямыми

Если прямые заданы угловыми коэффициентами $k_1$ и $k_2$:

\tan \phi = \left| \frac{k_2 - k_1}{1 + k_1 k_2} \right|

Если прямые заданы направляющими векторами $\vec{d_1} = (m_1, n_1)$ и $\vec{d_2} = (m_2, n_2)$:

\cos \phi = \frac{|\vec{d_1} \cdot \vec{d_2}|}{||\vec{d_1}|| \cdot ||\vec{d_2}||} = \frac{|m_1 m_2 + n_1 n_2|}{\sqrt{m_1^2 + n_1^2} \sqrt{m_2^2 + n_2^2}}
7. Расстояние между прямыми (от точки до прямой)

Расстояние $d$ от точки $P_0(x_0, y_0)$ до прямой Ax + By + C = 0:

d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}
