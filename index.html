Подготовка к экзамену по алгебре

Основные понятия, формулы и примеры

Прямая и Плоскость в Пространстве
1. Общее уравнение прямой

Общее уравнение прямой на плоскости имеет вид:

Ax + By + C = 0

Где A, B и C — постоянные, причем A и B не равны нулю одновременно. Этот вид удобен для определения нормального вектора прямой.

Пример:

Прямая 2x + 3y - 6 = 0. Если x = 0, то 3y = 6 => y = 2. Если y = 0, то 2x = 6 => x = 3. Прямая проходит через точки (0,2) и (3,0).

2. Уравнение прямой с угловым коэффициентом

Уравнение прямой с угловым коэффициентом:

y = kx + b

Где k — угловой коэффициент (k = tan alpha, где alpha — угол наклона прямой к положительному направлению оси Ox), b — отрезок, отсекаемый прямой на оси Oy.

Пример:

Прямая y = 2x + 1. Угловой коэффициент k = 2, отрезок по оси Oy b = 1. Это означает, что прямая пересекает ось Oy в точке (0,1) и имеет наклон, при котором на каждую единицу изменения x, y увеличивается на 2.

3. Уравнение прямой в отрезках

Уравнение прямой в отрезках:

x/a + y/b = 1

Где a — отрезок, отсекаемый прямой на оси Ox, b — отрезок, отсекаемый прямой на оси Oy.

Пример:

Прямая x/3 + y/2 = 1. Она пересекает ось Ox в точке (3,0) и ось Oy в точке (0,2).

4. Каноническое и параметрическое уравнения прямой

Каноническое уравнение прямой:

(x - x0) / m = (y - y0) / n

Где (x0, y0) — точка, через которую проходит прямая, и (m, n) — координаты направляющего вектора прямой.

Пример:

Прямая, проходящая через точку (1,2) с направляющим вектором (3,4): (x - 1) / 3 = (y - 2) / 4.

Параметрическое уравнение прямой:

x = x0 + mt
y = y0 + nt

Где (x0, y0) — точка, через которую проходит прямая, (m, n) — координаты направляющего вектора прямой, и t — параметр.

Пример:

Для той же прямой, проходящей через (1,2) с направляющим вектором (3,4):

x = 1 + 3t
y = 2 + 4t

При t=0, получаем точку (1,2). При t=1, получаем точку (4,6), которая также лежит на прямой.

5. Нормальный и направляющий вектор прямой

Нормальный вектор прямой:

Для общего уравнения прямой Ax + By + C = 0, нормальный вектор n имеет координаты:

n = (A, B)

Пример:

Для прямой 2x + 3y - 6 = 0, нормальный вектор n = (2, 3).

Направляющий вектор прямой:

Для канонического/параметрического уравнения прямой (x - x0) / m = (y - y0) / n, направляющий вектор d имеет координаты:

d = (m, n)

Для общего уравнения прямой Ax + By + C = 0, направляющий вектор может быть:

d = (-B, A) or d = (B, -A)

Пример:

Для прямой 2x + 3y - 6 = 0, направляющий вектор d = (-3, 2) или (3, -2).

6. Расстояние от точки до прямой

Расстояние d от точки P0(x0, y0) до прямой Ax + By + C = 0:

d = |Ax0 + By0 + C| / sqrt(A^2 + B^2)

Пример:

Найти расстояние от точки (1, -1) до прямой 3x + 4y + 5 = 0.

d = |3*1 + 4*(-1) + 5| / sqrt(3^2 + 4^2) = |3 - 4 + 5| / sqrt(9 + 16) = |4| / sqrt(25) = 4 / 5 = 0.8
7. Угол между двумя прямыми

Если прямые заданы угловыми коэффициентами k1 и k2:

tan phi = |(k2 - k1) / (1 + k1 * k2)|

Если прямые заданы направляющими векторами d1 = (m1, n1) и d2 = (m2, n2):

cos phi = |(d1 * d2)| / (length(d1) * length(d2)) = |m1*m2 + n1*n2| / (sqrt(m1^2 + n1^2) * sqrt(m2^2 + n2^2))

Пример:

Найти угол между прямыми y = 2x + 3 (k1 = 2) и y = -3x + 1 (k2 = -3).

tan phi = |(-3 - 2) / (1 + 2*(-3))| = |-5 / (1 - 6)| = |-5 / -5| = 1

Следовательно, phi = 45 градусов или pi/4 радиан.

8. Условие параллельности и перпендикулярности двух прямых

Параллельность:

Две прямые параллельны, если их угловые коэффициенты равны (k1 = k2) или если их направляющие векторы коллинеарны (d1 = lambda * d2).

Пример:

Прямые y = 3x + 1 и y = 3x - 5 параллельны, так как k1 = k2 = 3.

Перпендикулярность:

Две прямые перпендикулярны, если произведение их угловых коэффициентов равно -1 (k1 * k2 = -1) или если скалярное произведение их направляющих векторов равно 0 (d1 * d2 = 0).

Пример:

Прямые y = 2x + 1 и y = -0.5x + 3 перпендикулярны, так как 2 * (-0.5) = -1.

9. Общее уравнение плоскости

Общее уравнение плоскости в пространстве имеет вид:

Ax + By + Cz + D = 0

Где A, B, C и D — постоянные, причем A, B и C не равны нулю одновременно. Вектор n = (A, B, C) является нормальным вектором плоскости.

Пример:

Плоскость 2x - y + 3z - 6 = 0. Нормальный вектор этой плоскости n = (2, -1, 3).

10. Уравнение плоскости в отрезках

Уравнение плоскости в отрезках:

x/a + y/b + z/c = 1

Где a, b, c — отрезки, отсекаемые плоскостью на осях Ox, Oy, Oz соответственно.

Пример:

Плоскость x/2 + y/3 + z/4 = 1. Она пересекает ось Ox в точке (2,0,0), ось Oy в (0,3,0) и ось Oz в (0,0,4).

11. Расстояние от точки до плоскости

Расстояние d от точки P0(x0, y0, z0) до плоскости Ax + By + Cz + D = 0:

d = |Ax0 + By0 + Cz0 + D| / sqrt(A^2 + B^2 + C^2)

Пример:

Найти расстояние от точки (1, -2, 3) до плоскости 2x - 2y + z - 1 = 0.

d = |2*1 - 2*(-2) + 3*1 - 1| / sqrt(2^2 + (-2)^2 + 1^2) = |2 + 4 + 3 - 1| / sqrt(4 + 4 + 1) = |8| / sqrt(9) = 8 / 3

Кривые и Поверхности второго порядка
1. Уравнение окружности

Каноническое уравнение окружности с центром в точке (a, b) и радиусом R:

(x - a)^2 + (y - b)^2 = R^2

Если центр находится в начале координат (0,0):

x^2 + y^2 = R^2

Пример:

Окружность с центром в (1, -2) и радиусом 3 имеет уравнение: (x - 1)^2 + (y + 2)^2 = 3^2 = 9.

2. Уравнение эллипса

Каноническое уравнение эллипса с центром в начале координат:

x^2/a^2 + y^2/b^2 = 1

Где a и b — полуоси эллипса. Если a > b, фокусы лежат на оси Ox; если b > a, фокусы лежат на оси Oy.

Пример:

Эллипс x^2/25 + y^2/9 = 1 имеет полуоси a=5 и b=3. Фокусы находятся на оси Ox.

3. Уравнение гиперболы

Каноническое уравнение гиперболы с центром в начале координат:

x^2/a^2 - y^2/b^2 = 1

или

y^2/b^2 - x^2/a^2 = 1

Где a — действительная полуось, b — мнимая полуось. Асимптоты гиперболы: y = +/- (b/a)x.

Пример:

Гипербола x^2/16 - y^2/9 = 1 имеет действительную полуось a=4, мнимую полуось b=3. Асимптоты: y = +/- (3/4)x.

4. Уравнение параболы

Канонические уравнения параболы с вершиной в начале координат:

y^2 = 2px (ветви направлены вдоль оси Ox)
x^2 = 2py (ветви направлены вдоль оси Oy)

Где p — параметр параболы, равный расстоянию от фокуса до директрисы.

Пример:

Парабола y^2 = 4x. Здесь 2p = 4, значит p = 2. Фокус находится в точке (p/2, 0) = (1, 0), а уравнение директрисы x = -p/2 = -1.

5. Уравнение сферы

Каноническое уравнение сферы с центром в точке (a, b, c) и радиусом R:

(x - a)^2 + (y - b)^2 + (z - c)^2 = R^2

Если центр находится в начале координат (0,0,0):

x^2 + y^2 + z^2 = R^2

Пример:

Сфера с центром в (0,0,0) и радиусом 5 имеет уравнение: x^2 + y^2 + z^2 = 25.
