# Подготовка к экзамену по алгебре

Этот проект представляет собой простой веб-сайт для подготовки к экзамену по алгебре. 
Он содержит основные формулы и ответы на вопросы, организованные в виде меню.
## Особенности

*   **Статический сайт:** Полностью на HTML и CSS.
*   **Меню:** Темы и вопросы организованы с помощью HTML-тегов `<details>` и `<summary>`, что позволяет сворачивать и разворачивать разделы без JavaScript.
*   **Формулы:** Формулы представлены в формате LaTeX как текстовые строки.
    **Примечание:** Для корректного отображения математических символов LaTeX в браузере требуется JavaScript-библиотека (например, MathJax).
