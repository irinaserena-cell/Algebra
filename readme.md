# Подготовка к экзамену по алгебре

Этот проект представляет собой простой статический веб-сайт для подготовки к экзамену по алгебре. Он содержит основные формулы и ответы на вопросы, организованные в виде выпадающего меню.

## Особенности

*   **Статический сайт:** Полностью на HTML и CSS, без использования JavaScript.
*   **Выпадающее меню:** Темы и вопросы организованы с помощью HTML-тегов `<details>` и `<summary>`, что позволяет сворачивать и разворачивать разделы без JavaScript.
*   **Формулы:** Формулы представлены в формате LaTeX как текстовые строки и стилизованы зеленым цветом для лучшей читаемости.
    **Примечание:** Для корректного отображения математических символов LaTeX в браузере требуется JavaScript-библиотека (например, MathJax). Поскольку этот проект строго следует требованию "без JavaScript", формулы отображаются как обычный текст с соответствующим стилем.
*   **Ответы на вопросы:** Каждый вопрос содержит ответ, который можно раскрыть.
*   **Простой дизайн:** Чистый и минималистичный интерфейс.

## Как развернуть на GitHub Pages

1.  **Создайте репозиторий на GitHub:**
    *   Перейдите на GitHub и войдите в свою учетную запись.
    *   Нажмите кнопку "New" (Новый) для создания нового репозитория.
    *   Дайте ему имя, например, `algebra-exam-prep`.
    *   Выберите "Public" (Публичный) и нажмите "Create repository" (Создать репозиторий).

2.  **Загрузите файлы проекта:**
    *   Скопируйте файлы `index.html`, `style.css` и `README.md` в корневую папку нового репозитория.
    *   Вы можете сделать это через веб-интерфейс GitHub (кнопка "Add file" -> "Upload files") или с помощью Git-команд:
        ```bash
        git init
        git add .
        git commit -m "Initial commit for algebra exam prep site"
        git branch -M main
        git remote add origin https://github.com/ВАШ_НИКНЕЙМ/algebra-exam-prep.git
        git push -u origin main
        ```
        Замените `ВАШ_НИКНЕЙМ` на ваш реальный никнейм на GitHub.

3.  **Включите GitHub Pages:**
    *   В вашем репозитории на GitHub перейдите во вкладку "Settings" (Настройки).
    *   В левом боковом меню выберите "Pages".
    *   В разделе "Build and deployment" (Сборка и развертывание) выберите "Deploy from a branch" (Развернуть из ветки).
    *   В разделе "Branch" (Ветка) выберите `main` (или ту ветку, куда вы загрузили файлы) и папку `/ (root)`.
    *   Нажмите "Save" (Сохранить).

4.  **Дождитесь развертывания:**
    *   GitHub Pages начнет развертывание вашего сайта. Это может занять несколько минут.
    *   После завершения вы увидите URL вашего сайта (обычно `https://ВАШ_НИКНЕЙМ.github.io/algebra-exam-prep/`) на странице "Pages" в настройках репозитория.

Теперь ваш статический сайт будет доступен по указанному URL!
